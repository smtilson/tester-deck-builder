# tester-deck-builder
Deck builder with minimal features in order to enable deck building for play testers.


## Prompts regarding project
Minimal database for building decks of cards for play testers of a game.

Requirements:
1. Accounts with password recovery.
2. Some kind of invitation only link.
3. database of cards.
4. portal accessible to game developers.
5. deck building interface for playtesters with validated accounts.
6. validation of deck (meets deck building requirements)
7. filtration of cards by various features.
8. ability to save decks.
